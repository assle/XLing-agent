# 数据质量人工抽检清单

> 用于 ticket 01 的合成数据质量核查。重点排查会导致微调分类器学错的标签问题。

## 抽检方法

1. 从 `finetune/data/val.jsonl`（240 条）和 `finetune/data/train.jsonl`（2160 条）各随机抽 25 条，共约 50 条。
2. 逐条人工判断 instruction + input 对应的 output 标签是否正确。
3. 重点核查下方边界类型，记录疑似错标数量。

## 重点核查的边界类型

### 1. 焦虑 ↔ 低落（最易混淆）

焦虑（ANXIETY）强调紧张、担心、未来导向；低落（DEPRESSED）强调压抑、丧失兴趣、疲惫、过去导向。
核查点：含"压力""睡不着"的样本到底标焦虑还是低落，是否前后一致。

### 2. 高风险误标为低落/焦虑（最危险）

高风险（HIGH_RISK）应覆盖自伤、自杀、轻生意念。核查点：
- 含"撑不下去""消失""累赘"等委婉暗示的样本是否标为高风险而非低落。
- 含具体计划的样本是否标为高风险。

### 3. 正常误标为焦虑

含"考试""复习"但情绪平稳的吐槽是否被误标为焦虑。

### 4. 高风险关键词陷阱

含"自杀式复习""慢性自杀"等比喻用法的样本，期望标签取决于数据集口径：
- 若数据集把比喻视为正常/焦虑表达，则不应标为高风险。
- 核查现有标注是否与期望口径一致。
