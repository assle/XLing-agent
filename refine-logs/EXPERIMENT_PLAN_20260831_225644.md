# 通用心理支持分类器实验计划

## 目标

训练一个只输出“正常、焦虑、低落、高风险”的通用心理支持路由分类器。分类结果只用于消息分流和安全信号，不作诊断。

## 数据契约

- 场景覆盖：焦虑、低落、睡眠、工作、家庭、关系、适应、考试、普通聊天和明确高风险。
- 同一生成模板属于同一个 `sourceGroup`，不得跨训练、验证和独立测试集合。
- 生成后检查精确重复和字符三元组近重复；跨集合发现重复即失败。
- 独立测试集只在训练和模型选择结束后用于一次最终比较。

## 运行顺序

1. M0 数据生成与防泄漏检查。
2. M1 健全性测试：Qwen2.5-0.5B、少量训练步骤，确认损失下降且结果文件可解析。
3. M2 基座模型在独立测试集上的一次基线评测。
4. M3 LoRA 微调，验证集用于选择，不读取独立测试标签。
5. M4 微调模型在同一独立测试集上的一次最终评测。
6. M5 替换门槛：高风险召回不下降、宏平均 F1 提升、输出有效率不下降且本地推理延迟可接受。

## 固定配置

- 基座：`Qwen/Qwen2.5-0.5B-Instruct`
- 随机种子：42
- 最大长度：128
- LoRA rank：8
- 学习率：0.0002
- 训练轮数：2
- 批量大小：1，梯度累积：8
- 单样本实际生成延迟门槛：2000 毫秒
- 设备：Mac MPS
