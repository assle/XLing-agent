# Xling

Xling 是面向一般用户的非诊断性心理健康支持与咨询辅助系统。它帮助用户梳理焦虑、低落、睡眠、工作、家庭、关系、适应和考试压力等困扰；不进行疾病诊断、药物建议、独立治疗或紧急救援。系统可作为学校、医疗健康机构或普通健康平台的前置支持与人工分流工具，但真实部署仍需当地的专业、法律和安全审查。

## 五条展示主线

- 工作流与状态：LangGraph 是默认运行时；自研有限循环运行时可用于对照和依赖缺失时的基础降级。两者复用同一业务状态，高风险会在检索前暂停。
- 用户可控记忆：短期会话上下文、用户填写的支持背景与已确认记忆卡片分开保存；无记忆会话不创建新的长期记忆。
- RAG 与评测：Chroma 向量检索是在线默认路径，服务不可用时回退到本地混合检索。BGE、多查询、融合与重排仅用于离线比较。
- 安全评估与人工审核：明确高风险规则优先于分类器；高风险使用固定安全提示、最少必要的脱敏摘要与可恢复审核流程。审核人员可批准、拒绝、转介或安排后续关注。
- 工具执行与系统评测：持久化队列负责非阻塞投递、重试、租约与最终失败；MCP（模型上下文协议）提供可发现的外部工具适配。

## 三条演示旅程

1. 普通压力：表达工作、关系或考试压力，进入安全评估、四维梳理与短期行动计划。
2. 持续低落或睡眠受损：获得非诊断性支持、比例适当的专业支持建议，并可提交后续反馈。
3. 明确高风险：在知识检索前进入人工审核；用户立即收到稳定的安全提示，并被引导联系身边可信任的人、当地紧急服务或部署方资源。

## 启动

开发环境需要 Python 3.12：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Docker Compose 是默认演示方式：

```bash
docker compose up -d --build
```

服务会在 `http://127.0.0.1:8080` 提供界面。`AI_PROVIDER=mock` 可用于不连接模型的完整流程演示。Ollama、本地分类器和任何 OpenAI 兼容服务共用同一提供方配置；DeepSeek 作为兼容服务配置，而不是单独实现。

## 部署边界

基础仓库不硬编码学校、机构、热线或地区。部署方必须提供适用的专业支持与当地紧急资源。系统不会自动联系警方、急救中心、医院或现实联系人；它只提供资源信息并通知授权审核团队。

## 验证

```bash
.venv/bin/python -m pytest -q
.venv/bin/ruff check app evals tests
.venv/bin/mypy --ignore-missing-imports app evals
```

离线评测报告需明确标注数据、模型、提示词、知识与代码版本，并区分“实现并评测”“建议采用”和“在线使用”。概率校准与共形预测仅保留为离线探索性证据，不在在线风险链路加载。
