30 秒说明

Xling 是一个面向一般用户的非诊断性心理健康支持系统。它先判断消息属于普通交流还是心理支持，再对心理支持消息进行安全风险评估；低、中风险会进入知识检索和结构化追问，高风险则暂停自动流程并等待人工审核。系统用数据库保存关键事实，用短期存储保存会话状态，并把回答逐段发送到网页。

运行与入口Docker Compose、Caddy一起启动多个服务，并把外部请求转给应用docker-compose.yml、Caddyfile

三条主要分支

日常对话

快速安全检查 → 读取记忆 → 消息分流 → 日常回答。

心理支持

安全风险评估 → 知识检索 → 四维追问或行动计划 → 支持回复。

高风险消息

保存检查点 → 固定安全提示 → 等待人工审核 → 恢复或使用固定回复。

最容易混淆的边界

消息分流 ≠ 风险评估

前者选择处理路径，后者判断需要多高的安全保护。

角色 ≠ 独立模型

多个智能体名称表示不同职责，它们可以共享同一个模型和同一份状态。

Redis ≠ MySQL

Redis 主要承担有时限的短期状态；MySQL 保存必须长期可靠保留的业务事实。
