# Triage Labels

工程技能使用五种固定的问题分类角色。下表记录它们在本项目中的实际标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断如何处理 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可由自动化工程代理处理 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 决定不处理 |

工程技能提到某个分类角色时，使用表中对应的 GitHub 标签。
