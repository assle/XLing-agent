# LangGraph 统一编排与本地执行诊断

为避免图连接与另一套调度进度协议同时决定执行顺序，LangGraph 统一负责编排和状态更新，节点返回明确的字段更新。结构化执行记录用于解释分支依据、失败位置和阶段耗时，覆盖图内步骤以及图外的回复与保存。

## 编排与状态

- 完整删除自研有限循环、自动回退入口和旧共享上下文协议，LangGraph 成为唯一编排方式；依赖不可用时明确报错，不切换到另一种运行器。
- 用明确的 `GraphState` 替代共享可变 `AgentContext`；节点读取所需状态，返回本节点产生的字段更新，执行顺序由图连接保证。
- 新流程只使用新的图状态格式，不保留旧上下文读写适配或检查点迁移路径，旧图执行状态不接入新流程。
- 移除仅用于旧调度资格检查的进度标志；消息分流、安全风险评估、人工审核决定和认知行为四维追问结果仍以明确业务状态表达。
- 每次新消息完整初始化本轮状态，避免同一会话上一轮的回复、检索结果或业务事件残留；长期记忆和检查点各自维持原有职责。
- 新流程保留安全风险评估先正常返回保存、再进入人工审核关口的顺序，以及批准、拒绝和新流程检查点不可用时的安全行为；这些行为不承担旧格式兼容职责。
- 同一会话处于待审核状态时不接收新一轮消息，其他会话照常；界面呈现等待状态，服务端在提交新的图输入前校验持久化审核状态，避免仅靠按钮限制而覆盖暂停点。审核决定完成后，该会话才恢复普通消息处理。
- 保持现有业务结果和 SSE 事件的含义；诊断记录不作为业务分支的输入。

## 执行诊断

- 面向本地部署联调，覆盖请求开始、图前准备、节点执行、条件分支、图后保存、流式回复、请求结束和后续人工审核恢复。
- 节点和阶段在执行时记录开始、结束或失败，异常前已经完成的记录可独立查看，不依赖整轮成功返回。人工审核暂停作为独立状态记录并继续交由 LangGraph 处理；恢复时重新进入审核关口，不把正常暂停误报为异常或重复成功执行。
- 被业务代码捕获后继续执行的失败也记录固定原因码、异常类别和操作耗时，区分正常结果与降级结果；图完成、回复生成完成和数据保存完成分别记录。
- 记录分支依据及相关判断值、阶段耗时和异常类别；堆栈只取文件、函数与行号，不采集异常原文、源码行、局部变量或异常附带的请求响应对象。普通诊断记录不复制用户正文、完整模型输入输出或整份检查点状态；覆盖阶段的既有降级日志也使用同一内容边界。
- 每次聊天执行或审核恢复生成独立 `run_id`；恢复关联同一轮聊天首次执行的编号，该首次执行也使用 LangGraph。首次执行编号保存在检查点中，会话线程编号继续用于检查点定位，运行耗时与审核等待分别表达。
- 终端显示简短摘要，本地 JSONL 文件保存结构化记录，支持按单次执行编号筛选。采用 `data/logs/`、单文件 10 MiB 和 5 个轮转文件，针对本地单应用进程的启动方式；日志从 Git 和发布包排除。
- 诊断输出失败不改变业务结果，终端发出简短提示；业务异常和取消继续按原有语义传播，不被日志包装吞掉。
- 后台报告和通知任务通过现有消息、报告、审核和任务编号与请求记录关联；任务入队与实际执行结果分别表达。

## 本地切换

本地切换清空旧聊天、审核、后台任务和检查点，以新请求重新联调。离线重置命令分别核验 SQL、会话缓存、图状态和导出文件，并返回保留数据的前后数量；清理未完成时明确返回失败。

- 以全部应用进程及运行中的工作任务实际退出为停写边界；仅调用后台工作器的停止方法不足以保证正在执行的任务已经结束。
- 清理旧会话、消息及关联的安全评估、审核、工具任务、失败留存、通知与台账记录，以及会话关联的行动计划、行动项、次日反馈和风险轨迹。
- 按退休会话公开编号清理 Redis 短期消息与四维追问状态；清理对应检查点存储及其 WAL/SHM 文件、失效检查点清理任务和旧报告的本地台账导出。
- 账户、支持背景、已确认记忆卡片、独立自愿量表筛查、知识库、模型和配置不属于此次会话数据重置范围；不删除整个 `data/` 目录或应用数据卷。
- 联调以不携带旧会话编号的新请求开始，确认新会话、新状态和新任务均由 LangGraph 流程创建。

## 验收目标

- 日常对话、心理支持追问、行动计划和安全升级保持现有业务含义；同一会话连续两轮不残留上一轮的回复、检索或业务事件。
- 新流程高风险评估在暂停前已保存，完整重启后可批准或拒绝；批准后才生成正文，拒绝不生成，新检查点不可用时安全降级。待审核会话的新消息在图运行前被拒绝，原暂停状态保持可恢复，其他会话可正常处理。
- 正常执行、被捕获的模型降级、节点异常、流式生成异常和取消均可从记录定位阶段、原因与耗时；审核恢复能关联首次执行并分别计时。
- 用合成敏感标记验证终端和 JSONL 的内容边界；验证诊断写入失败不阻断业务，以及本地旧数据清理后不存在可执行的退休任务或可读取的退休会话状态。

## 与既有决策的关系

保留 ADR-0001 的异步图运行、ADR-0002 的可序列化持久检查点、ADR-0003 的评估与中断节点分离、ADR-0004 的恢复安全降级，以及 ADR-0010 的安全评估顺序。ADR-0003 和 ADR-0005 的正文使用节点返回更新和独立审核决定、追问结果表达当前行为；条件边路由方式继续保留。
