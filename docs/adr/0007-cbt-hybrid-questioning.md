# 认知行为四维追问采用混合模式

认知行为四维追问采用混合模式：触发事件、想法、身体反应和行为四个方面必须全部覆盖，语言模型负责每个方面的自然措辞和跟进。不选纯固定序列，因为机械感强；也不选完全由语言模型自由追问，因为无法保证四个方面完整，难以稳定验证。混合方案让固定规则保证完整性，让语言模型保证自然度。

四方面首次完整时生成该会话的行动计划。生成请求同时保留用户最新原话、近期表达、可读取的支持背景和已确认记忆，避免四维摘要遗漏时间、工作职责和不可改变的安排；最新纠正优先于较早内容。后续对话复用最新计划及其已保存条目、完成状态，不因四维状态仍完整而再建计划。页面按当前会话读取计划，切换历史会话不会显示其他会话的计划；首页和未发送消息的新会话不显示历史计划。条目调整通过界面“替换”保存，回复不能声称已代替用户修改。最新计划完成后，面板不退回较旧的进行中计划，后续回复也不能要求使用已隐藏的勾选、替换或反馈入口。
