# 多语言知识检索以 dense 为主并保留词法兜底

## 背景

ADR-0025 的原查询＋通道感知 RRF 在真实复测中只有 26/30，且出现一个安全关键漏检。使用同次 DeepSeek 改写和完整阶段轨迹继续对照，所有包含 BM25 名次奖励的公式均不超过 26/30；dense-only＋原查询为 30/30，安全关键漏检为 0。中英文资料混合时，词法通道不仅对英文候选零覆盖，还会持续引入与查询表面词项匹配但语义不适用的高名次候选。

## 决策

- 在线多查询检索以当前 multilingual dense 名次作为唯一主排序信号，原查询与改写查询继续全部参与，跨查询保留每个片段的最佳 dense 分数。
- BM25 不再与有效 dense 结果叠加计票；向量服务不可用时仍走既有本地混合兜底，不因本决策降低检索可用性。
- 旧混合 RRF 实现保留为私有 `_retrieve_hybrid_rrf`，离线实验统一经 `KnowledgeService.retrieve_experiment` 调用；配置值 `multi_query_hybrid_rrf` 暂作为兼容标识保留，但状态标签必须准确显示实际的 dense-primary 行为。归一化加权可选配置不变。
- ADR-0025 的通道感知 RRF 方案被本决策取代。采用前完成原回归集、冻结集与未参与调整的新查询验证，并分别记录各集合的用途。

## 后果

检索避免跨语言 BM25 断层和双路计票造成的系统性挤压，实现也更简单。代价是有效 dense 路径不再利用精确词项匹配，专业名词、编号或新术语查询可能更依赖向量模型覆盖；这些场景必须进入新查询验证，未来若要恢复词法融合需先证明不重新引入安全漏检。

## 验收

- 有效向量路径只按 dense 名次融合，诊断轨迹不再把 BM25 名次计入结果；向量不可用时本地兜底仍可返回结果。
- 原查询保留、改写去重及失败降级回归保持通过。
- 冻结集目标来源 Recall@4 至少 90%，安全关键漏检为 0；原回归集与全新查询分别报告，不能以冻结集结果替代。
- 若原回归或安全关键场景退化，回退到 ADR-0017 的对照方案并重新评估，而不是只报告冻结集收益。

## 验证结果（2026-11-02）

使用独立 `dense-primary` 评测入口、真实 Chroma 向量与 DeepSeek 改写复测：冻结集 29/30，目标来源 Recall@4 为 96.67%，5 个安全关键题目标来源漏检为 0；方案确定后运行的 12 题 holdout 为 11/12，Recall@4 为 91.67%，2 个安全关键题目标来源漏检为 0。背景中的 30/30 来自同次轨迹的离线重放，最终实现复测以 29/30 为准。

原 100 题回归保留完整原始结果，目标来源 Recall@4 为 61.00%；其中 36 题期望已经删除的 `campus-mental-health.md` 或 `counselor-referral-and-resources.md`，标为 `stale-source`，原标签保持不变。现行来源可判定的 64 题为 61/64，Recall@4 为 95.31%。`risk-professional-support` 是 1/32 个目标来源安全漏检；其他现行资料命中预期答案词项，因此回答相关性口径的安全漏检为 0。逐题结果见优化报告。
