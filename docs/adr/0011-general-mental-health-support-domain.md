# 通用心理健康支持与机构支持分流

## 状态

Accepted

## 背景

医院与大学的心理健康服务需要明确系统与专业人员的分工：非高风险心理支持需求由系统承接，高风险需求由医生或心理健康专业人员负责。通用支持流程应覆盖不同困扰来源，考试压力作为其中一个主题。

系统提供心理健康支持与咨询辅助，医疗诊断、药物建议和治疗决策属于专业人员职责。支持分流与技术审核状态不能被表述为专业服务已经完成。

## 决策

Xling 是一个通用的心理健康支持与咨询辅助系统，以医院和大学的心理健康服务为主要场景。非高风险心理支持需求由系统提供持续支持，高风险需求进入机构指定医生或专业人员负责的支持路径。

统一使用用户、支持分流、支持背景、授权审核人员、安全评估记录以及专业支持与当地紧急资源等正式术语。授权审核人员代表机构承担专业支持职责，技术管理权限本身不等于专业处置资格。机构负责专业人员、通知渠道和当地资源的适用性，系统不硬编码特定机构。

产品需求与验收要求以 [Xling 主规格](https://github.com/assle/XLing-agent/issues/14) 为准。考试压力、工作、家庭、关系、睡眠、适应和低落均进入统一支持流程；诊断、药物与治疗决策由专业人员负责。

## 后果

正面：

- 系统承接非高风险支持需求，专业人员负责高风险需求，服务分工清晰；
- 同一支持流程覆盖医院与大学中的不同用户和困扰来源；
- 用户可控记忆、知识支持、行动反馈和可恢复状态服务于连续支持。

负面：

- 机构需要组织实际可用的专业支持人员和服务渠道，并核对资源适用性；
- 专业支持衔接需要业务验收，不能只用通知发送或后台审批结果证明；
- 系统的支持与分流定位不代表已完成临床有效性或正式合规认证。
