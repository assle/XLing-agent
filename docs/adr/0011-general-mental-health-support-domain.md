# 通用心理健康支持与咨询辅助作为当前领域范围

## 状态

Accepted

## 背景

Xling 原先将备考焦虑作为唯一支持闭环。该范围便于演示阶段感知和校园资源，但会把用户身份、支持背景、知识库和安全资源不必要地绑定到学生与学校，无法表达系统在医疗健康机构或普通健康平台中的支持与人工分流能力。

系统不具备疾病诊断、药物建议、独立治疗、医疗合规认证或自动紧急救援能力，因此不能通过把“校园”替换为“医疗”来宣称自己是医疗诊断系统。

## 决策

将 Xling 定位为面向一般用户的非诊断性心理健康支持与咨询辅助系统。考试压力保留为一个知识主题和评测子集，但不再控制全局用户身份、支持背景、接口或默认资源。

系统使用用户、支持背景、授权审核人员、安全评估记录以及专业支持与当地紧急资源作为正式术语。部署方可以提供学校、医疗健康机构或普通健康平台的资源包；基础系统不硬编码某个学校或地区。

## 后果

正面：

- 支持闭环可以覆盖工作、家庭、关系、睡眠、适应和考试压力等场景；
- 人工审核、用户可控记忆、RAG 和工具链保持可解释的 Agent 工程价值；
- 产品不再通过校园身份限制一般用户。

负面：

- 现有备考画像、校园知识、提示词、分类数据和评测需要逐步迁移；
- 扩展范围不允许被表述为医疗诊断或治疗能力；
- 部署方需要自行维护适用的专业支持与当地紧急资源。
