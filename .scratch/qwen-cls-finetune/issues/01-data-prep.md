# 01 - 数据准备与质量检查

**What to build:** 从现有 2400 条合成情绪四分类数据出发，切分出可复现的训练集和验证集，并注册为训练框架可识别的数据集，同时产出一份人工抽检清单，为后续训练和评估提供现成数据。

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] 2400 条数据按 9:1 切分，验证集每类 60 条共 240 条，切分使用固定随机种子保证可复现
- [ ] 训练集与验证集分别保存，标签保持中文（正常/焦虑/低落/高风险）不动
- [ ] 数据集已注册为 LLaMA-Factory 可识别格式，训练命令能直接以数据集名加载
- [ ] 产出一份人工抽检清单，标注重点核查的边界 case 类型（焦虑↔低落、高风险误标为低落等），并记录抽检结论与疑似错标数量
